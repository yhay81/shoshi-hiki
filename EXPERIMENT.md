# 35-day observation

The first release asks whether anonymous visitors move from a title, creator, or ISBN query to an official NDL record, bibliographic copy, a local saved card, and a later return.

Read the funnel in order: visitor, searcher, successful result, official reader, citation copier, saver, returner. Automated QA is marked separately and excluded.

If visitors do not search, improve the three entry modes and examples. If no-result usage is high, improve normalization and query guidance. If official opens or copies occur, invest in edition comparison and export formats. If saves and returns occur, improve local organization. Add accounts only when cross-device demand is visible.

The evaluation date is 2026-09-06 JST.
