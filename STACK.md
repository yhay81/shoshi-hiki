# Stack

- Cloudflare Workers
- Hono and Hono JSX
- Vite+
- Cloudflare D1 for short-lived aggregateable event rows
- Durable Objects for serialized official API access and in-memory result reuse
- fast-xml-parser with schema and size guards
- TypeScript and Vitest
- Browser `localStorage` for bibliographic cards

Better Auth is intentionally absent because the released job does not require an account or cross-device state.
